# Soft-edge proof route for the Phase 4 trace asymptotic

This note records a possible route from the formal symbol calculation in `PHASE4_LOG2_ASYMPTOTIC_HEURISTIC.md` to a rigorous finite-section asymptotic.

## Relevant external framework

A directly relevant primary reference is:

- Grzegorz Świderski, *Periodic perturbations of unbounded Jacobi matrices III: The soft edge regime*, arXiv:1707.06486.

The paper studies unbounded Jacobi matrices when zero lies at a soft edge of the associated periodic model. Of particular interest for the present bench:

- it treats linear and sublinear growth regimes;
- it develops transfer-matrix control of the soft edge;
- it gives an explicit representation of the inverse in the model setting;
- the spectral phase-transition analysis uses Hardy-type estimates.

This does **not** directly prove the trace asymptotic needed here. The present observable contains `K^{-1/2}`, not merely a resolvent or `K^{-1}`, and the bench concerns finite compressions with a weighted perturbation `H`.

## Match with the Phase 4 archimedean block

After alternating conjugation, each large-index parity block has the formal structure

```text
K
 = -nabla^*(b_i nabla) + V_i + ...
```

with

```text
b_i = i/(4*pi) + O(1),
V_i = 1/(64*pi*i) + O(i^-2).
```

Thus the off-diagonal Jacobi scale grows linearly and zero is a quadratic soft edge of the frozen symbol.

The sign-corrected first-order perturbation has

```text
H
 = -nabla^*(o_i nabla) + W_i + ...
```

with

```text
o_i = O(i^-1/2),
W_i = 1/(2*pi^(3/2)*sqrt(i)) + O(i^-3/2).
```

The leading trace singularity is therefore generated by the interaction of

```text
K^(-1/2)
```

with the multiplication-like weight `W_i` at the soft edge.

## Exact integral representation to exploit

For every positive finite matrix `K`,

```text
K^(-1/2)
 = (1/pi) integral_0^infinity
     t^(-1/2) (K+t I)^(-1) dt.
```

Therefore one parity contribution can be rewritten exactly as

```text
(1/2) Tr(K^(-1/2) H)
 = 1/(2*pi)
   integral_0^infinity
     t^(-1/2)
     Tr[(K+t I)^(-1) H]
   dt.
```

This representation turns the singular square-root trace into a weighted integral of resolvent traces. It is a more natural point of contact with Jacobi soft-edge resolvent techniques than applying a generic spectral-distribution theorem directly to `x^(-1/2)`.

## Proposed proof decomposition

A rigorous program can be organized into four scales.

### 1. Bulk away from zero

For `t` bounded below relative to the local `1/i` soft-edge scale, use ordinary resolvent identities and the slowly varying Jacobi coefficients to compare finite sections with frozen local models. This part should contribute at most `O(log m)` after summation.

### 2. Soft-edge window

For

```text
t ~ 1/i,
theta ~ 1/i,
```

retain both terms in

```text
k(i,theta)
 ~ i theta^2/(4*pi)
   + 1/(64*pi*i).
```

The exact `1/(64*pi*i)` residual prevents a genuine zero in the finite local model and fixes the infrared scale responsible for the logarithm.

### 3. Weighted trace

Show that the gradient part of `H` is lower order in the singular window, while

```text
W_i
 ~ 1/(2*pi^(3/2)*sqrt(i))
```

can be replaced by its leading value with a summable trace error. The target local contribution is

```text
(log i)/(2*pi^2*i)
```

per parity.

### 4. Summation and boundaries

Prove that

```text
sum_{i<=m} (log i)/i
 = (1/2)(log m)^2 + O(log m),
```

and that the first finitely many rows, parity offset `epsilon`, and terminal boundary contribute only to lower-order terms.

This would give

```text
S(m)
 = (1/(2*pi^2))(log m)^2
   + O(log m)
```

for the two parity blocks together.

## Main unresolved estimate

The key missing theorem is a uniform finite-section bound of the form

```text
Tr[(K_m+tI)^(-1)H_m]
 = local_soft_edge_model(m,t)
   + controlled_error(m,t)
```

with an error that remains integrable against `t^(-1/2) dt` and summable over the slowly varying index.

The soft-edge Jacobi literature provides a plausible language for the resolvent part, but the weighted trace and the finite-section uniformity must still be established specifically for this operator.

## Why this route is preferable to another giant matrix run

The coefficient `1/(2*pi^2)` now arises from exact leading row coefficients. Increasing `m` can refine the numerical picture, but it cannot replace the missing uniform soft-edge estimate.

The next computational tests should therefore validate asymptotic row coefficients and error terms needed by the proof, rather than only extend `S(m)` to larger dimensions.

## Scientific boundary

Even a proof of this finite-compression asymptotic would be a theorem about the semilocal prolate bench, not a proof of the Riemann hypothesis and not an identification of finite compression crossings with zeta zeros.
